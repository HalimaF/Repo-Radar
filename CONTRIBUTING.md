# Contributing to Repo Radar

Thanks for helping. Bug reports, fixes and small focused features are all welcome.

## Set up

```bash
npm ci
npm test
```

To try your change in Chrome: open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked** and pick this folder. Reload the extension after each edit.

## Making a change

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Branch from `master`.
3. Keep logic in `src/lib/` free of `chrome.*` calls. That is what keeps it testable.
4. Add or update a test in `tests/` for any logic you change.
5. Run `npm test`. CI runs the same command on every pull request and must pass.
6. Open a pull request that says what changed and why.

## Ground rules

- No runtime npm dependencies. The extension ships only what is in `src/`, `vendor/` and `icons/`.
- Scores and verdicts are computed from data, never generated by an LLM.
- Don't commit tokens or other secrets.

## Reporting a security problem

Please don't open a public issue. See [SECURITY.md](SECURITY.md).
